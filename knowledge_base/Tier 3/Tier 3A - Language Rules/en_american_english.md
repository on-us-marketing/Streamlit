# EN Language Rules - American English

Last updated: July 2026
Status: Draft for review
Use stage: Repurposing

## Official EN Standard

On-us English content should use American English.

This rule applies to Blog and LinkedIn repurposing by default. Use British English only when the human input explicitly requests it or an approved co-branded asset requires that spelling. A named client alone does not automatically override the language standard unless the content request or approved reference confirms the override.

Use:

- behavior
- behavioral
- analyze
- optimize
- program
- color
- center
- personalized
- customizable

Avoid:

- behaviour
- behavioural
- analyse
- optimise
- programme
- colour
- centre
- personalised
- customisable

## Tone

EN content should be:

- Confident
- Clear
- Outcome-led
- Professional but human
- Data-supported
- Easy to scan

## Core Tone Attributes

| Attribute | How to write |
|---|---|
| Confident and results-driven | Lead with proof, not unsupported promises |
| Concise and direct | Use short sentences and active voice |
| Empowering, not prescriptive | Show how marketers can do more without sounding preachy |
| Globally fluent, locally relevant | Keep APAC context where relevant |
| Tech-forward but human | AI and FinTech are enablers. Outcomes are the main story |

## Writing Rules

Do:

- Lead with client problem or market insight
- Tie features to business outcomes
- Use proof points only when relevant
- Explain AI in practical terms
- Keep sentences clear

Do not:

- Overuse AI buzzwords
- Use vague SaaS filler
- Use em dashes
- Use unsupported superlatives
- Use dense paragraphs

## Message Architecture

Use this order when adapting a master brief into EN content:

1. Hook with a marketer pain point or market insight
2. Explain the On-us solution angle
3. Connect features to measurable business value
4. Add social proof if relevant
5. End with a clear CTA
