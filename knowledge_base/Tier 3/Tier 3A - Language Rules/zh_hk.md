# ZH-HK Language Rules

Last updated: July 2026
Status: Draft for review
Use stage: Repurposing

## Market Scope

Use this file for Traditional Chinese Hong Kong content.

## Core Language Style

ZH-HK content should be:

- Professional
- Direct
- Business-oriented
- Clear for banks, insurers, corporates, and marketers
- Less overly polished or AI-sounding

## Preferred Terms

| EN term | ZH-HK usage |
|---|---|
| Smart E-Voucher | 智能電子禮券 |
| Value Added Solutions | 全方位獎賞加值套件 |
| Green & ESG Solution | 綠色可持續禮券方案 |
| Wellness Voucher | 健康生活禮券 |
| ESG Voucher | ESG 禮券 |
| Green Voucher | 綠色減碳禮券 |
| Merchant | 商戶 |
| Reward | 獎賞 |
| Customer engagement | 客戶互動 |
| Redemption | 兌換 |
| Fraud | 欺詐 |
| KOL | KOL |

## Avoid

- 台灣用語 such as 智慧電子禮券 when HK context requires 智能電子禮券
- 詐騙 in formal financial contexts, use 欺詐
- 網紅, use KOL
- Overly casual consumer slang
- Overly technical surveillance language

## Writing Guidance

Good HK content should connect product functions to business outcomes, such as:

- 提升禮券開啟及兌換意慾
- 減少人手處理獎賞流程
- 提升活動後數據洞察
- 支援銀行、保險及企業客戶的大規模獎賞活動
