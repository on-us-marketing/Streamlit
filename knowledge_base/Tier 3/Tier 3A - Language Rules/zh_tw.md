# ZH-TW Language Rules

Last updated: July 2026
Status: Draft for review
Use stage: Repurposing

## Market Scope

Use this file for Traditional Chinese Taiwan content.

## Core Language Style

ZH-TW content should be:

- Professional
- Clear
- Slightly warmer than HK business writing
- Suitable for Taiwan banks, insurers, brands, and enterprise marketers

## Preferred Terms

| EN term | ZH-TW usage |
|---|---|
| Smart E-Voucher | 智慧電子禮券 |
| Value Added Solutions (VAS) | 全方位獎勵加值套件 |
| Green & ESG Solution | 綠色永續禮券方案 |
| Wellness Voucher | 健康生活禮券 |
| ESG Voucher | ESG 禮券 |
| Green Voucher | 綠色減碳禮券 |
| Merchant | 商家 / 商戶, depending on context |
| Reward | 獎勵 |
| Customer engagement | 顧客互動 |
| Redemption | 兌換 |
| KOL | KOL |

## Avoid

- Hong Kong-specific terminology when writing for Taiwan
- Mentioning On-us Express unless approved
- Overly technical surveillance wording
- Overclaiming market coverage

## On-us Express

Do not recommend On-us Express for Taiwan market content unless this changes and is approved.

## Official Boilerplate Reference

For formal Taiwan Traditional Chinese company description, refer to:

```text
Tier 1 - Factual Foundation/official_boilerplate.md
```

Use the TW-TC boilerplate wording when the output is a company profile, press release, website description, award submission, or partner-facing introduction.

## Writing Guidance

Good Taiwan content should explain:

- How Smart E-Vouchers support campaign engagement
- How rewards can connect online and offline customer journeys
- How enterprise marketers can use behavioral signals for better follow-up
- How event or employee rewards can be distributed more efficiently
