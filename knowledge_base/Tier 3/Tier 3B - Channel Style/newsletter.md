# Newsletter Style Guide

Last updated: July 2026
Status: Draft for review
Use stage: Repurposing

## Purpose

Use this file to adapt a master content brief into a newsletter or email-style update.

## Recommended Structure

```text
Subject line:
Preview text:
Opening:
Main update:
Why it matters:
On-us relevance:
CTA:
```

## Tone

Newsletter content should be:

- Short
- Clear
- Useful
- Less promotional than LinkedIn
- Action-oriented

## Writing Rules

Do:

- Make the subject line specific
- Keep opening concise
- Focus on one message per email
- Use bullets for readability
- Add one clear CTA

Avoid:

- Too many claims
- Too many links
- Long company-centered paragraphs
- Overly formal announcement tone

## CTA Examples

- Read the full article
- Explore the campaign use case
- Book a demo
- Contact us to learn more
