## Source-of-Truth Rule

All public-facing proof points should be pulled from this file instead of being repeated across multiple content files. If numbers change, update this file first.

Before using any proof point, read `claim_scope_hierarchy.md` to confirm whether the number is company-level, platform-level, product-level, campaign-level, or client-level.

Do not move a broad proof point down into a more specific claim unless the source clearly supports that exact scope.

Example:

```text
50M+ consumer reach = company / platform scale.
It does not mean one campaign reached 50M+ consumers.
```

## Overall-Level Platform Proof Points

The following metrics are overall-level platform proof points. They can be used for broad capability-level content, such as company profile, platform overview, or general campaign performance positioning.

- 75% average voucher open rate
- 65% average campaign cost saving
- 70%+ conversion rate
- 2.5 minutes average voucher interaction time

They should not be automatically applied to a specific campaign, client, vertical, or market unless the source clearly links the number to that exact context.

Do not use them for:

- A specific client case
- A specific market
- A specific campaign type
- A before / after comparison
- A product feature claim that is not directly tied to the number

## How to Use Proof Points

Use proof points to support factual claims, not as decoration.

Good:

```text
With 3,000+ merchants and 400,000+ physical store touchpoints, On-us helps marketers build reward campaigns that connect digital issuance with real-world redemption.
```

Avoid:

```text
On-us is the best reward platform with unmatched scale.
```

## Claims Requiring Extra Confirmation

The following should not be invented or attributed to a specific client without approval:

- Exact ROI uplift
- Client-specific conversion rate
- Client-specific campaign revenue
- Partner-specific campaign results not already approved
- Market share claims
- Exclusive partnership claims
- 500,000 outlet / POS footprint wording from FAQ, because the current approved proof point in this file is 400,000+ physical store touchpoints
- 2 minutes average voucher engagement wording from FAQ, because the current approved proof point in this file is 2.5 minutes average voucher interaction time
- 85% higher conversion for On-us Form, unless approved for the specific content
- Enterprise minimum order value or pricing terms, unless approved for the specific content
- Any cost-saving formula marked for removal in source materials
